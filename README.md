# SENAI Systems Development

A collection of exercises and small projects developed during my Technical Course in Systems Development at SENAI (2020–2021).

This repository brings together academic projects created while learning software development fundamentals, object-oriented programming, databases, web development, and mobile development.

## 📚 Technologies

The exercises in this repository include:

- C#
- .NET / ASP.NET Core
- SQL
- React Native
- JavaScript
- Expo

## 📂 Repository Structure

### C#

Exercises focused on C# fundamentals, object-oriented programming, file handling, and ASP.NET Core.

- `poo-celular` — Object-oriented programming fundamentals
- `agenda-console` — Console contact management application with file persistence
- `mvc-console` — Basic MVC architecture applied to a console application
- `aspnet-core-basics` — Introduction to ASP.NET Core MVC
- `product-file-console` — Product management exercise using file persistence

### SQL

Exercises focused on relational databases and SQL fundamentals.

- `sql-basics` — DDL, DML, queries, and JOIN exercises

### React Native

Mobile development exercises created with React Native and Expo.

- `basic-form` — Basic form and state management exercise
- `camera` — Camera access and permissions exercise
- `navigation-basics` — Basic React Native navigation exercise
